# VidButler

[English](../README.md)

VidButler — кросплатформний медіапомічник на базі Electron, який використовує **yt-dlp** і **FFmpeg**. Завантажуйте відео й аудіо з YouTube, X (Twitter), Instagram і сотень інших сайтів. Можна вибирати формат, витягувати субтитри, перекодовувати відео й вбудовувати субтитри в зображення. У режимі ШІ можна отримати стислий переказ відео на основі доступних субтитрів і завантажити уривок з онлайн-джерела, указавши час початку й кінця.

У програмі є два інтерфейси, між якими можна перемикатися в будь-який час:

- **Класичний режим** — форма для введення посилання, вибору дії та налаштування файлів cookie й проксі.
- **Режим ШІ** — опишіть завдання своїми словами, наприклад *«Завантаж це відео і вбудуй англійські субтитри»*. Програма перетворює запит на безпечні команди `yt-dlp` або `FFmpeg` та виконує їх.

Натисніть піктограму VidButler, щоб відкрити **Про VidButler**. У меню **Мова** можна вибрати англійську, німецьку, французьку, іспанську, італійську, польську, нідерландську, португальську, спрощену або традиційну китайську, японську, російську чи українську. Параметр **Мова системи** враховує налаштування операційної системи й вибирає англійську, якщо відповідної мови немає. VidButler зберігає вибір після перезапуску.

## Можливості

- **Два інтерфейси** — перемикайтеся між класичною формою та розмовою із ШІ.
- **Підтримка багатьох платформ** — завантажуйте медіа через `yt-dlp` з YouTube, X, Instagram, TikTok та інших сайтів.
- **Якість і формат** — вибирайте роздільність і контейнер або витягуйте лише звук (M4A, MP3, Opus, FLAC, WAV).
- **Вбудовані мініатюри** — програма вбудовує мініатюру в завантажене відео, якщо формат це підтримує. Мініатюру можна зберегти окремо.
- **Субтитри** — завантажуйте субтитри вибраною мовою або вбудовуйте їх у верхню чи нижню частину зображення.
- **Перекодування в MP4** — перетворюйте відео за допомогою FFmpeg на широко сумісні файли MP4 з H.264/AAC.
- **Апаратне прискорення** — у macOS використовується VideoToolbox для вбудовування субтитрів і створення підтримуваних фрагментів MP4.
- **Файли cookie** — використовуйте файли cookie з Chrome, Firefox, Brave або Safari для завантаження відео з віковими обмеженнями або відео лише для учасників.
- **Проксі HTTP і SOCKS5** — спрямовуйте завантаження й запити через локальний або віддалений проксі. Увімкніть **Проксі**, виберіть тип і введіть хост і порт.
- **Скасування** — зупиняйте поточне завантаження чи кодування. Після перерваного завантаження в папці завантажень можуть залишитися неповні файли.

## Установлення

Готові пакети містять yt-dlp, FFmpeg і Deno. Виберіть `arm64` для Apple Silicon, Windows на Arm або Linux ARM64. Виберіть `x64` для Mac з Intel і більшості комп’ютерів з Windows або Linux та процесором Intel чи AMD.

### Спосіб 1 — Homebrew (macOS)

Установлюйте й оновлюйте програму через Homebrew:

```bash
brew install --cask Shawshank01/tap/vidbutler
```

### Спосіб 2 — Пряме завантаження

1. Завантажте найновішу версію зі сторінки [випусків](https://github.com/Shawshank01/Vidbutler/releases).
2. Запустіть інсталятор для вашої операційної системи:
   - **macOS:** `.dmg`
   - **Windows:** інсталятор `.exe`
   - **Linux:** `.AppImage`

> [!IMPORTANT]
> Програму для macOS підписано підписом ad hoc, і вона не пройшла нотаризацію в Apple. macOS може заблокувати пряме встановлення з DMG. Рекомендовано встановлювати через Homebrew. Якщо завантажили програму безпосередньо, можливо, доведеться вибрати **Відкрити попри це** в розділі **Системні параметри > Приватність і безпека** або виконати `xattr -cr /Applications/VidButler.app`.

### Спосіб 3 — З вихідного коду

Робочі процеси CI використовують Node.js 26 і pnpm 12. Перед запуском `pnpm start` установіть yt-dlp і FFmpeg. У macOS виконайте `brew install yt-dlp ffmpeg`, в Ubuntu або Debian — `sudo apt install yt-dlp ffmpeg`. У Windows додайте інструменти до `PATH`. Для вбудовування субтитрів потрібна збірка FFmpeg із фільтром `subtitles`, наприклад `ffmpeg-full` з Homebrew. Установіть Deno для [повної підтримки YouTube](https://github.com/yt-dlp/yt-dlp/wiki/EJS).

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/Shawshank01/Vidbutler.git
   cd Vidbutler
   ```

2. Установіть залежності:

   ```bash
   pnpm install
   ```

3. Запустіть програму:

   ```bash
   pnpm start
   ```

   *(У macOS можна також двічі натиснути `start.command` у кореневій папці проєкту, щоб установити залежності й запустити програму.)*

#### Збирання пакетів

Щоб створити інсталятор для поточної платформи:

```bash
pnpm run build
```

Інсталятори й виконувані файли зберігаються в папці `dist/`.

Випуски для macOS використовують підпис ad hoc, для якого не потрібні облікові дані Apple Developer Program. Після оновлення macOS може знову попросити доступ до браузера. Збірки Windows підписуються, якщо налаштовано необов’язкові секрети `WIN_CSC_LINK` і `WIN_CSC_KEY_PASSWORD`.

## Видалення

Щоб видалити версію Homebrew та її локальні дані, закрийте VidButler і виконайте `brew uninstall --cask --zap Shawshank01/tap/vidbutler`. За ручного встановлення перед видаленням програми виберіть **Про VidButler → Видалити локальні дані**. Це видалить налаштування, збережені ключі API й кеш, яким керує програма. Завантажені файли залишаться. У macOS версії для розробки й розповсюдження мають спільні дані. Очищення не охоплює записи В’язки ключів macOS, кеші окремих інструментів і попередніх версій VidButler.

## Використання режиму ШІ

Натисніть **ШІ** у верхньому правому куті, щоб відкрити чат. Своїми словами можна просити завантажити, перетворити чи перевірити медіа або виконати дії з файлами.

### Приклади запитів

- *«Завантаж це відео: https://…»*
- *«Завантаж це відео в 720p: https://…»*
- *«Завантаж уривок від 0:45 до 2:10: https://…»*
- *«Завантаж аудіо від 1:15 до 2:30: https://…»*
- *«Збережи аудіо з цього відео у форматі M4A»*
- *«Коротко перекажи це відео: https://…»*
- *«Якими мовами є субтитри до цього відео?»*, а потім *«Вбудуй англійські субтитри вгорі»*
- *«Завантаж відео, а потім перекодуй його в сумісний MP4»*
- *«Покажи, що є в моїй папці завантажень»* / *«Видали файли субтитрів, які залишилися»*

Уривки можна завантажувати з онлайн-джерел. Для цього потрібен FFmpeg. Щоб скористатися проксі, виберіть **HTTP** і введіть адресу HTTP-проксі з підтримкою CONNECT. Якщо проксі підтримує лише SOCKS5, використайте локальний міст HTTP–SOCKS5. Стислий переказ спирається на доступні субтитри й може містити часові позначки. Довгі транскрипти можуть потребувати кількох запитів до постачальника ШІ.

### Налаштування постачальника

1. Натисніть **ШІ** у верхньому правому куті й відкрийте **Налаштування ШІ**.
2. Виберіть постачальника й перевірте модель. Якщо потрібен ключ API, вставте його й натисніть **Зберегти ключ**. Для Ollama чи сервера, сумісного з OpenAI, перевірте адресу сервера.
3. Натисніть **Перевірити з’єднання**, а потім **Зберегти**.
4. Виберіть папку завантажень і почніть розмову.

| Постачальник | Вимоги | Примітки |
| --- | --- | --- |
| **Cohere** (типовий, модель `command-a-plus-05-2026`) | Ключ API з [панелі керування Cohere](https://dashboard.cohere.com/api-keys) | Найбільш рекомендований варіант. Безплатного тарифу достатньо для щоденного використання. |
| **Google Gemini** (модель `gemini-3.5-flash-lite`) | Ключ API з [Google AI Studio](https://aistudio.google.com/apikey) | Ця модель має [безплатний тариф](https://aistudio.google.com/docs/pricing#gemini-3.5-flash-lite). Ваші повідомлення надсилаються в Google. |
| **xAI Grok** (модель `grok-4.3`) | Ключ API з [консолі xAI](https://console.x.ai) | Скористайтеся ним, щоб підтримати «Рокетс». |
| **Ollama (локально)** | Запущена [Ollama](https://ollama.com) з моделлю, що підтримує виклики інструментів, наприклад `lfm3:1.7b`. | З локальною моделлю й сервером програма надсилає дані розмови до Ollama на вашому комп’ютері. |
| **Сумісний з OpenAI** | URL сервера, назва моделі та зазвичай ключ API | Працює з llama.cpp, OpenAI, OpenRouter, Groq, LM Studio й подібними сервісами. |

Для завантаження й обробки медіа виберіть модель із підтримкою викликів інструментів.

Додаткові налаштування:

- **Глибина міркувань** — Gemini та xAI мають власні налаштування. Значення **Немає** вимикає міркування в Grok 4.3 і застосовує типове значення для інших моделей xAI.
- **Рівень підтвердження** — виберіть, коли запитувати дозвіл: *Лише для ризикованих дій* (типово), *Перед кожною дією* або *Ніколи*.

Після помилки HTTP 503 програма зазвичай повторює запит до моделі один раз. Після HTTP 429 вона повторює запит, якщо постачальник указав дійсний час очікування в `Retry-After` до 60 секунд. Якщо виникла помилка автентифікації, перевірте ключ у **Налаштуваннях ШІ** й натисніть **Перевірити з’єднання**.

### Приватність і безпека

- **Дані для постачальника** — програма надсилає вибраному постачальнику вміст чату, визначення інструментів і результати їх виконання. Результати можуть містити назви відео, субтитри, назви файлів і шлях до папки завантажень.
- **Зберігання ключів API** — форма налаштувань передає ключ головному процесу. Збережені ключі шифруються локально за допомогою `safeStorage` від Electron. Якщо захищене сховище недоступне, ключі залишаються в пам’яті протягом поточного сеансу.
- **Історія чату** — VidButler тримає історію в пам’яті, доки ви не почнете новий чат або не закриєте програму. Хмарні постачальники обробляють отримані дані за власними правилами зберігання.
- **Дії з файлами** — помічник працює з медіафайлами у вибраній папці завантажень. Типові налаштування вимагають підтвердження видалення файлів.

## Використання класичного режиму

У класичному режимі ключ API для ШІ не потрібен.

1. Вставте посилання на відео й виберіть папку призначення.
2. Виберіть дію:
   - **Завантажити відео (найкраща якість)** — завантажує найкращий доступний потік.
   - **Показати формати** — показує всі доступні потоки та їхні коди форматів.
   - **Завантажити у вибраному форматі** — введіть код формату. Щоб побачити доступні варіанти, спочатку виберіть **Показати формати**. Виберіть код аудіоформату, щоб завантажити лише звук.
   - **Завантажити мініатюру** — зберігає лише зображення мініатюри.
   - **Завантажити субтитри** — показує доступні доріжки субтитрів і дає змогу вибрати, які зберегти.
   - **Завантажити й перекодувати в MP4 високої якості (H.264/AAC)** — перекодовує з H.264/AAC для максимальної сумісності відтворення.
   - **Завантажити й вбудувати субтитри у відео** — вбудовує субтитри безпосередньо у верхню або нижню частину зображення.
3. За потреби виберіть **Браузер для отримання файлів cookie**, наприклад для приватних посилань або відео з віковими обмеженнями, чи налаштуйте **Проксі**.
4. Натисніть **Виконати**.

Щоб зупинити поточне завдання, натисніть **Скасувати дію**. Після скасування перекодування чи вбудовування субтитрів VidButler видаляє незавершені файли FFmpeg. Після перерваного завантаження можуть залишитися неповні файли.

## Оновлення

Зібрані пакети для macOS і Windows та Linux AppImage перевіряють випуски GitHub під час запуску.

1. У **Windows і Linux AppImage** виберіть **Завантажити й перезапустити**. Програма перевірить контрольну суму, встановить оновлення й автоматично запустить нову версію.
2. У **macOS** виберіть **Скопіювати команду Homebrew**, а потім вставте команду в Термінал, щоб оновити tap і встановити нову версію.

   ```bash
   brew update --force && brew upgrade --cask Shawshank01/tap/vidbutler
   ```

   Якщо ви встановили VidButler безпосередньо з DMG, виберіть **Відкрити випуск на GitHub**.
3. Щоб перевірити оновлення вручну, натисніть піктограму VidButler і виберіть **Перевірити оновлення**.

> [!NOTE]
> Під час запуску з вихідного коду або розпакованої збірки Linux пункт **Перевірити оновлення** пропонує відкрити [найновіший випуск](https://github.com/Shawshank01/Vidbutler/releases/latest).

## Використані проєкти

- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — основний рушій для завантаження медіа
- [FFmpeg](https://ffmpeg.org/) — обробка й перекодування аудіо та відео, вбудовування субтитрів
- [Deno](https://deno.com/) — легке середовище JavaScript для проходження перевірок у yt-dlp
- [Electron](https://www.electronjs.org/) — фреймворк для настільних програм
