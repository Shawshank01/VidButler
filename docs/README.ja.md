# VidButler

[English](../README.md)

VidButler は Electron 製のクロスプラットフォーム対応メディアアシスタントです。**yt-dlp** と **FFmpeg** を使い、YouTube、X（Twitter）、Instagram など数百のサイトから動画や音声をダウンロードできます。形式の指定、字幕の抽出、動画の再エンコード、字幕の焼き込みにも対応しています。AI モードでは、利用可能な字幕をもとに動画を要約できます。開始時刻と終了時刻を指定して、オンラインのソースからクリップをダウンロードすることもできます。

2 種類のインターフェースをいつでも切り替えられます。

- **クラシックモード**。URL の入力、操作の選択、Cookie やプロキシの設定をフォームで行います。
- **AI モード**。*「この動画をダウンロードして英語字幕を焼き込んで」* のように、やりたいことを普段の言葉で伝えます。アプリが依頼を安全な `yt-dlp` または `FFmpeg` のコマンドに変換して実行します。

VidButler のアイコンをクリックして **VidButler について** を開き、**言語** から英語、ドイツ語、フランス語、スペイン語、イタリア語、ポーランド語、オランダ語、ポルトガル語、中国語（簡体字）、中国語（繁体字）、日本語、ロシア語、ウクライナ語を選択できます。**システムの言語** は OS の言語設定に従い、対応する言語がない場合は英語を使用します。VidButler は選択した言語を再起動後も保持します。

## 機能

- **2 種類のインターフェース**。クラシックフォームと AI チャットをいつでも切り替えられます。
- **幅広いプラットフォームに対応**。`yt-dlp` を使って YouTube、X、Instagram、TikTok などからメディアをダウンロードできます。
- **画質と形式を指定**。解像度やコンテナーを選択できます。音声のみの抽出にも対応します（M4A、MP3、Opus、FLAC、WAV）。
- **サムネイルの埋め込み**。対応する形式では、ダウンロードした動画にサムネイルを埋め込みます。画像だけを保存することもできます。
- **字幕の処理**。言語を指定して字幕をダウンロードしたり、動画の上部または下部に字幕を焼き込んだりできます。
- **MP4 への再エンコード**。FFmpeg を使って、広い互換性を持つ H.264/AAC の MP4 に動画を変換します。
- **ハードウェアアクセラレーション**。macOS では字幕の焼き込みと対応する MP4 クリップの作成に VideoToolbox を使います。
- **Cookie に対応**。Chrome、Firefox、Brave、Safari の Cookie を使って、年齢制限のある動画や会員限定の動画をダウンロードできます。
- **HTTP・SOCKS5 プロキシ**。ローカルまたはリモートのプロキシ経由でダウンロードや問い合わせを行えます。**プロキシ** を有効にし、種類を選んでホストとポートを入力します。
- **キャンセル**。ダウンロードやエンコードを途中で停止できます。ダウンロードを中断すると、ダウンロード先に未完了のファイルが残る場合があります。

## インストール

配布パッケージには yt-dlp、FFmpeg、Deno が含まれます。Apple Silicon、Arm 版 Windows、ARM64 Linux には `arm64` を選択してください。Intel Mac と、Intel または AMD 搭載の一般的な Windows・Linux PC には `x64` を選択してください。

### 方法 1 — Homebrew（macOS）

Homebrew でインストールやアップデートを行います。

```bash
brew install --cask Shawshank01/tap/vidbutler
```

### 方法 2 — 直接ダウンロード

1. [リリース](https://github.com/Shawshank01/Vidbutler/releases) ページから最新版をダウンロードします。
2. 使用している OS 向けのインストーラーを実行します。
   - **macOS:** `.dmg`
   - **Windows:** `.exe` インストーラー
   - **Linux:** `.AppImage`

> [!IMPORTANT]
> macOS 版はアドホック署名されており、Apple の公証は受けていません。macOS が DMG からの直接インストールをブロックすることがあります。macOS では Homebrew を推奨します。直接ダウンロードした場合、**システム設定 > プライバシーとセキュリティ** で **このまま開く** を選択する必要がある場合があります。代替手段として `xattr -cr /Applications/VidButler.app` を実行することもできます。

### 方法 3 — ソースコードから起動

CI ワークフローは Node.js 26 と pnpm 12 を使用します。`pnpm start` を実行する前に yt-dlp と FFmpeg をインストールしてください。macOS では `brew install yt-dlp ffmpeg`、Ubuntu または Debian では `sudo apt install yt-dlp ffmpeg` を実行します。Windows ではツールを `PATH` に追加します。字幕の焼き込みには Homebrew の `ffmpeg-full` など、`subtitles` フィルター付きの FFmpeg ビルドが必要です。[YouTube に完全対応する](https://github.com/yt-dlp/yt-dlp/wiki/EJS) には Deno をインストールしてください。

1. リポジトリをクローンします。

   ```bash
   git clone https://github.com/Shawshank01/Vidbutler.git
   cd Vidbutler
   ```

2. 依存関係をインストールします。

   ```bash
   pnpm install
   ```

3. アプリを起動します。

   ```bash
   pnpm start
   ```

   *（macOS では、プロジェクトのルートにある `start.command` をダブルクリックして、依存関係をインストールし、そのままアプリを起動することもできます。）*

#### 配布パッケージのビルド

現在のプラットフォーム向けのインストーラーを作成します。

```bash
pnpm run build
```

インストーラーと実行ファイルは `dist/` ディレクトリに出力されます。

macOS リリースにはアドホック署名を使用するため、Apple Developer Program の認証情報は不要です。アップデート後に macOS からブラウザーへのアクセス許可を再度求められる場合があります。Windows ビルドはオプションのシークレット `WIN_CSC_LINK` と `WIN_CSC_KEY_PASSWORD` が設定されている場合に署名されます。

## アンインストール

Homebrew 版とそのローカルデータを削除するには、VidButler を終了して `brew uninstall --cask --zap Shawshank01/tap/vidbutler` を実行してください。手動でインストールした場合は、アプリを取り除く前に **VidButler について → ローカルデータを削除** を使用してください。設定、保存済みの API キー、アプリが管理するキャッシュが消去されます。ダウンロード済みのファイルは保持されます。macOS では開発版とリリース版がこのデータを共有します。macOS キーチェーンの項目と、単独で使用したツールや旧版の VidButler のキャッシュは削除対象外です。

## AI モードの使い方

右上の **AI** をクリックしてチャットを開きます。ダウンロード、変換、メディア情報の確認、ファイル管理などを普段の言葉で依頼できます。

### 依頼の例

- *「この動画をダウンロードして：https://…」*
- *「この動画を 720p でダウンロードして：https://…」*
- *「この動画の 0:45 から 2:10 までをダウンロードして：https://…」*
- *「1:15 から 2:30 までの音声をダウンロードして：https://…」*
- *「この動画の音声を M4A で保存して」*
- *「この動画を要約して：https://…」*
- *「この動画の字幕は何語に対応している？」* と聞き、続けて *「英語字幕を上部に焼き込んで」* と依頼する
- *「ダウンロードしてから、互換性の高い MP4 に再エンコードして」*
- *「ダウンロード先のファイルを表示して」* / *「残っている字幕ファイルを削除して」*

クリップのダウンロードはオンラインのソースに対応し、FFmpeg が必要です。プロキシ経由の場合は **HTTP** を選び、CONNECT に対応する HTTP プロキシのアドレスを入力してください。SOCKS5 しか使えない場合は、ローカルで HTTP から SOCKS5 へのブリッジを使用してください。動画の要約には利用可能な字幕を使用し、時間を示すこともできます。長い文字起こしの場合は、AI プロバイダーに複数回リクエストを送ることがあります。

### プロバイダーの設定

1. 右上の **AI** をクリックして **AI 設定** を開きます。
2. プロバイダーを選び、モデルを確認します。API キーが必要な場合は貼り付けて **キーを保存** をクリックします。Ollama や OpenAI 互換サーバーを使う場合は、サーバーのアドレスを確認します。
3. **接続をテスト**、**保存** の順にクリックします。
4. ダウンロード先を選択してチャットを始めます。

| プロバイダー | 要件 | 備考 |
| --- | --- | --- |
| **Cohere**（既定、モデル `command-a-plus-05-2026`） | [Cohere ダッシュボード](https://dashboard.cohere.com/api-keys) の API キー | 最もおすすめです。日常的な利用には無料枠で十分です。 |
| **Google Gemini**（モデル `gemini-3.5-flash-lite`） | [Google AI Studio](https://aistudio.google.com/apikey) の API キー | このモデルには [無料枠](https://aistudio.google.com/docs/pricing#gemini-3.5-flash-lite) があります。メッセージは Google へ送信されます。 |
| **xAI Grok**（モデル `grok-4.3`） | [xAI コンソール](https://console.x.ai) の API キー | ロケッツを応援したいなら使ってみてください。 |
| **Ollama（ローカル）** | `lfm3:1.7b` など、ツール呼び出しに対応するモデルで [Ollama](https://ollama.com) を起動 | ローカルモデルとローカルサーバーを使用する場合、チャットデータは自分のコンピューター上の Ollama に送られます。 |
| **OpenAI 互換** | サーバー URL、モデル名、通常は API キー | llama.cpp、OpenAI、OpenRouter、Groq、LM Studio などに対応します。 |

ダウンロードやメディア処理を行うには、ツール呼び出しに対応するモデルを選んでください。

その他の設定

- **推論の強度**。Gemini と xAI にはそれぞれの設定があります。**なし** を選ぶと Grok 4.3 の推論が無効になり、ほかの xAI モデルではモデルの既定値が使われます。
- **確認のレベル**。確認する操作を *リスクのある操作のみ*（既定）、*すべての操作*、*確認しない* から選びます。

モデルへのリクエストが HTTP 503 で失敗した場合、通常は一度だけ再試行します。HTTP 429 の場合は、プロバイダーが `Retry-After` で 60 秒以内の有効な待機時間を指定した場合に再試行します。認証エラーが出た場合は **AI 設定** でキーを確認し、**接続をテスト** をクリックしてください。

### プライバシーとセキュリティ

- **プロバイダーに送信される情報**。チャットの内容、ツールの定義、ツールの実行結果を選択したプロバイダーに送信します。実行結果には動画のタイトル、字幕、ファイル名、ダウンロード先のパスなどが含まれることがあります。
- **API キーの保管**。設定フォームはキーをメインプロセスに渡します。保存済みのキーは Electron の `safeStorage` を使ってローカルで暗号化されます。安全に保管できない場合、キーは実行中のセッションの間だけメモリに保持されます。
- **チャット履歴**。VidButler は新しいチャットを始めるかアプリを終了するまで、履歴をメモリに保持します。ホスティング型のプロバイダーはそれぞれの保存ポリシーに従って送信データを扱います。
- **ファイル操作**。アシスタントは選択したダウンロード先にあるメディアを操作します。既定の設定ではファイルの削除前に確認が必要です。

## クラシックモードの使い方

クラシックモードでは AI の API キーは不要です。

1. 動画の URL を貼り付け、保存先を選びます。
2. 操作を選びます。
   - **動画をダウンロード（最高画質）**。利用できる中で最高画質のストリームをダウンロードします。
   - **利用可能な形式を表示**。利用可能なストリームと形式コードを表示します。
   - **ダウンロード（カスタム形式）**。形式コードを指定します。先に **利用可能な形式を表示** を実行すると選択肢を確認できます。音声のみのコードを選ぶと音声だけがダウンロードされます。
   - **サムネイルをダウンロード**。サムネイル画像だけを保存します。
   - **字幕をダウンロード**。利用できる字幕トラックの一覧から保存するものを選びます。
   - **ダウンロードして高画質 MP4（H.264/AAC）に再エンコード**。再生互換性を高めるため、H.264/AAC で再エンコードします。
   - **ダウンロードして字幕を焼き込む**。動画の上部または下部に字幕を直接焼き込みます。
3. 必要に応じて **Cookie を取得するブラウザー** を選択するか、**プロキシ** を設定します。Cookie は年齢制限のある動画や非公開のリンクに役立ちます。
4. **実行** をクリックします。

処理中のタスクを止めるには **操作をキャンセル** をクリックします。再エンコードや字幕の焼き込みをキャンセルすると、VidButler は FFmpeg の未完了の出力を削除します。ダウンロードを中断すると未完了のファイルが残ることがあります。

## アップデート

macOS と Windows の配布パッケージ、および Linux AppImage は起動時に GitHub のリリースを確認します。

1. **Windows と Linux AppImage** では **ダウンロードして再起動** を選びます。チェックサムを検証してアップデートをインストールし、新しいバージョンを自動で起動します。
2. **macOS** では **Homebrew のコマンドをコピー** を選び、ターミナルに貼り付けて tap を更新し、最新版をインストールします。

   ```bash
   brew update --force && brew upgrade --cask Shawshank01/tap/vidbutler
   ```

   VidButler を DMG から直接インストールした場合は、**GitHub のリリースを開く** を選びます。
3. 手動で確認するには、VidButler のアイコンをクリックして **アップデートを確認** を選びます。

> [!NOTE]
> ソースコードからの起動時や展開済みの Linux ビルドでは、**アップデートを確認** から [最新リリース](https://github.com/Shawshank01/Vidbutler/releases/latest) を開けます。

## 謝辞

- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — メディアをダウンロードするための中核エンジン
- [FFmpeg](https://ffmpeg.org/) — 音声・動画の処理、トランスコード、字幕の焼き込み
- [Deno](https://deno.com/) — yt-dlp のチャレンジを解くための軽量 JavaScript ランタイム
- [Electron](https://www.electronjs.org/) — デスクトップアプリケーションのフレームワーク
