# VidButler

[English](../README.md)

VidButler — кроссплатформенный медиапомощник на Electron, использующий **yt-dlp** и **FFmpeg**. Скачивайте видео и аудио с YouTube, X (Twitter), Instagram и сотен других сайтов. Вы можете выбирать формат, извлекать субтитры, перекодировать видео и встраивать субтитры в изображение. В режиме ИИ можно получить краткий пересказ видео на основе доступных субтитров и скачать фрагмент из онлайн-источника, указав время начала и окончания.

В приложении два интерфейса. Переключаться между ними можно в любой момент:

- **Классический режим** — форма для ввода ссылки, выбора действия и настройки файлов cookie и прокси.
- **Режим ИИ** — опишите задачу своими словами, например *«Скачай это видео и встрой английские субтитры»*. Приложение преобразует запрос в безопасные команды `yt-dlp` или `FFmpeg` и выполняет их.

Нажмите значок VidButler, чтобы открыть **О VidButler**. В меню **Язык** можно выбрать английский, немецкий, французский, испанский, итальянский, польский, нидерландский, португальский, упрощённый или традиционный китайский, японский, русский или украинский. Параметр **Язык системы** учитывает языковые предпочтения операционной системы и выбирает английский, если подходящего языка нет. VidButler запоминает выбор после перезапуска.

## Возможности

- **Два интерфейса** — переключайтесь между классической формой и чатом с ИИ.
- **Поддержка множества платформ** — скачивайте медиа через `yt-dlp` с YouTube, X, Instagram, TikTok и других сайтов.
- **Качество и формат** — выбирайте разрешение и контейнер или извлекайте только звук (M4A, MP3, Opus, FLAC, WAV).
- **Встроенные миниатюры** — приложение встраивает миниатюры в скачанные видео, если формат это поддерживает. Миниатюры можно сохранять отдельно.
- **Работа с субтитрами** — скачивайте субтитры на выбранном языке или встраивайте их в изображение сверху либо снизу.
- **Перекодирование в MP4** — преобразуйте видео с помощью FFmpeg в широко совместимые файлы MP4 с H.264/AAC.
- **Аппаратное ускорение** — в macOS используется VideoToolbox для встраивания субтитров и создания поддерживаемых фрагментов MP4.
- **Файлы cookie** — передавайте файлы cookie из Chrome, Firefox, Brave или Safari для скачивания видео с возрастными ограничениями или видео только для участников.
- **Прокси HTTP и SOCKS5** — направляйте загрузки и запросы через локальный или удалённый прокси. Включите **Прокси**, выберите тип и укажите хост и порт.
- **Отмена** — останавливайте загрузку или кодирование. При прерванной загрузке в папке загрузок могут остаться неполные файлы.

## Установка

Готовые пакеты включают yt-dlp, FFmpeg и Deno. Выбирайте `arm64` для Apple Silicon, Windows на Arm или Linux ARM64. Выбирайте `x64` для Mac с Intel и большинства компьютеров с Windows или Linux и процессором Intel либо AMD.

### Способ 1 — Homebrew (macOS)

Установка и обновление через Homebrew:

```bash
brew install --cask Shawshank01/tap/vidbutler
```

### Способ 2 — Прямое скачивание

1. Скачайте последнюю версию со страницы [выпусков](https://github.com/Shawshank01/Vidbutler/releases).
2. Запустите установщик для вашей операционной системы:
   - **macOS:** `.dmg`
   - **Windows:** установщик `.exe`
   - **Linux:** `.AppImage`

> [!IMPORTANT]
> Приложение для macOS подписано подписью ad hoc и не прошло нотариальное заверение Apple. macOS может заблокировать прямую установку из DMG. Рекомендуется устанавливать через Homebrew. При прямом скачивании может понадобиться выбрать **Всё равно открыть** в разделе **Системные настройки > Конфиденциальность и безопасность** или выполнить `xattr -cr /Applications/VidButler.app`.

### Способ 3 — Из исходного кода

Рабочие процессы CI используют Node.js 26 и pnpm 12. Для `pnpm start` установите yt-dlp и FFmpeg. В macOS выполните `brew install yt-dlp ffmpeg`, в Ubuntu или Debian — `sudo apt install yt-dlp ffmpeg`. В Windows добавьте инструменты в `PATH`. Для встраивания субтитров нужна сборка FFmpeg с фильтром `subtitles`, например `ffmpeg-full` из Homebrew. Установите Deno для [полной поддержки YouTube](https://github.com/yt-dlp/yt-dlp/wiki/EJS).

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Shawshank01/Vidbutler.git
   cd Vidbutler
   ```

2. Установите зависимости:

   ```bash
   pnpm install
   ```

3. Запустите приложение:

   ```bash
   pnpm start
   ```

   *(В macOS можно дважды нажать `start.command` в корневом каталоге проекта, чтобы установить зависимости и запустить приложение.)*

#### Сборка пакетов

Чтобы создать установщик для текущей платформы:

```bash
pnpm run build
```

Установщики и исполняемые файлы сохраняются в каталоге `dist/`.

Выпуски для macOS используют подпись ad hoc, для которой не нужны учётные данные Apple Developer Program. После обновления macOS может снова запросить доступ к браузеру. Сборки Windows подписываются, если настроены необязательные секреты `WIN_CSC_LINK` и `WIN_CSC_KEY_PASSWORD`.

## Удаление

Чтобы удалить версию Homebrew и её локальные данные, закройте VidButler и выполните `brew uninstall --cask --zap Shawshank01/tap/vidbutler`. При ручной установке перед удалением приложения выберите **О VidButler → Удалить локальные данные**. Это удалит настройки, сохранённые ключи API и кэш, которым управляет приложение. Скачанные файлы сохранятся. В macOS версии для разработки и распространения используют общие данные. Очистка не затрагивает записи связки ключей macOS, кэши отдельных инструментов и старых версий VidButler.

## Использование режима ИИ

Нажмите **ИИ** в правом верхнем углу, чтобы открыть чат. Своими словами попросите скачать, преобразовать или проверить медиафайлы либо выполнить операции с файлами.

### Примеры запросов

- *«Скачай это видео: https://…»*
- *«Скачай это видео в 720p: https://…»*
- *«Скачай фрагмент видео с 0:45 по 2:10: https://…»*
- *«Скачай аудио с 1:15 по 2:30: https://…»*
- *«Сохрани аудио этого видео в M4A»*
- *«Кратко перескажи это видео: https://…»*
- *«Какие языки субтитров доступны для этого видео?»*, затем *«Встрой английские субтитры в верхнюю часть изображения»*
- *«Скачай видео и перекодируй его в совместимый MP4»*
- *«Покажи содержимое моей папки загрузок»* / *«Удали оставшиеся файлы субтитров»*

Фрагменты можно скачивать из сетевых источников. Для этого нужен FFmpeg. При работе через прокси выберите **HTTP** и укажите адрес HTTP-прокси с поддержкой CONNECT. Если прокси предлагает только SOCKS5, используйте локальный мост HTTP–SOCKS5. Краткие пересказы опираются на доступные субтитры и могут содержать ссылки на временные отметки. Длинные расшифровки могут потребовать нескольких запросов к поставщику ИИ.

### Настройка поставщика

1. Нажмите **ИИ** в правом верхнем углу и откройте **Настройки ИИ**.
2. Выберите поставщика и проверьте модель. Если нужен ключ API, вставьте его и нажмите **Сохранить ключ**. Для Ollama или сервера, совместимого с OpenAI, проверьте адрес сервера.
3. Нажмите **Проверить подключение**, затем **Сохранить**.
4. Выберите папку загрузок и начните беседу.

| Поставщик | Требования | Примечания |
| --- | --- | --- |
| **Cohere** (модель `command-a-plus-05-2026`) | Ключ API из [панели управления Cohere](https://dashboard.cohere.com/api-keys) | Наиболее рекомендуемый вариант. Бесплатного тарифа достаточно для повседневного использования. |
| **Google Gemini** (по умолчанию, модель `gemini-3.5-flash-lite`) | Ключ API из [Google AI Studio](https://aistudio.google.com/apikey) | У модели по умолчанию есть [бесплатный тариф](https://aistudio.google.com/docs/pricing#gemini-3.5-flash-lite). Ваши сообщения отправляются в Google. |
| **xAI Grok** (модель `grok-4.3`) | Ключ API из [консоли xAI](https://console.x.ai) | Используйте его, чтобы поддержать «Рокетс». |
| **Ollama (локально)** | Запущенная [Ollama](https://ollama.com) с моделью, поддерживающей вызов инструментов, например `lfm3:1.7b`. | При локальной модели и локальном сервере приложение отправляет данные чата в Ollama на вашем компьютере. |
| **Совместимый с OpenAI** | URL сервера, название модели и, как правило, ключ API | Работает с llama.cpp, OpenAI, OpenRouter, Groq, LM Studio и аналогичными сервисами. |

Для скачивания и обработки мультимедиа выберите модель с поддержкой вызова инструментов.

Дополнительные настройки:

- **Глубина рассуждений** — для Gemini и xAI предусмотрены собственные настройки. Значение **Нет** отключает рассуждения в Grok 4.3 и оставляет глубину по умолчанию в других моделях xAI.
- **Уровень подтверждения** — выберите, когда запрашивать разрешение: *Только для рискованных действий* (по умолчанию), *Перед каждым действием* или *Никогда*.

При ошибке HTTP 503 приложение обычно повторяет запрос к модели один раз. При HTTP 429 повтор выполняется, если поставщик указывает в `Retry-After` допустимое время ожидания до 60 секунд. При ошибке аутентификации проверьте ключ в **Настройках ИИ** и нажмите **Проверить подключение**.

### Конфиденциальность и безопасность

- **Данные, отправляемые поставщику** — приложение передаёт выбранному поставщику содержимое чата, определения инструментов и их результаты. Результаты могут содержать названия видео, субтитры, имена файлов и путь к папке загрузок.
- **Хранение ключей API** — форма настроек передаёт ключ главному процессу. Сохранённые ключи шифруются локально с помощью `safeStorage` из Electron. Если защищённое хранилище недоступно, ключи остаются в памяти до конца текущего сеанса.
- **История чата** — VidButler хранит историю в памяти до начала нового чата или выхода из приложения. Поставщики облачных услуг хранят полученные данные по своим правилам.
- **Операции с файлами** — помощник работает с медиафайлами в выбранной папке загрузок. Настройки по умолчанию требуют подтверждать удаление файлов.

## Использование классического режима

Для классического режима не нужен ключ API поставщика ИИ.

1. Вставьте ссылку на видео и выберите папку назначения.
2. Выберите действие:
   - **Скачать видео (наилучшее качество)** — скачивает лучший доступный поток.
   - **Показать форматы** — показывает все доступные потоки и их коды формата.
   - **Скачать в выбранном формате** — введите код формата. Чтобы узнать доступные варианты, сначала выберите **Показать форматы**. Чтобы скачать только звук, выберите код аудиоформата.
   - **Скачать миниатюру** — сохраняет только изображение миниатюры.
   - **Скачать субтитры** — показывает доступные дорожки субтитров и позволяет выбрать те, которые нужно сохранить.
   - **Скачать и перекодировать в MP4 высокого качества (H.264/AAC)** — использует H.264/AAC для максимальной совместимости при воспроизведении.
   - **Скачать и вшить субтитры в видео** — встраивает субтитры непосредственно в верхнюю или нижнюю часть изображения.
3. При необходимости выберите **Браузер для получения файлов cookie** для закрытых ссылок или видео с возрастными ограничениями либо настройте **Прокси**.
4. Нажмите **Выполнить**.

Чтобы остановить текущую задачу, нажмите **Отменить действие**. При отмене перекодирования или встраивания субтитров VidButler удаляет незавершённые файлы FFmpeg. После прерванной загрузки могут остаться неполные файлы.

## Обновление

Готовые сборки для macOS и Windows, а также Linux AppImage проверяют выпуски на GitHub при запуске.

1. В **Windows и Linux AppImage** выберите **Скачать и перезапустить**. Приложение проверит контрольную сумму, установит обновление и автоматически запустит новую версию.
2. В **macOS** выберите **Скопировать команду Homebrew** и вставьте команду в Терминал, чтобы обновить tap и установить новую версию.

   ```bash
   brew update --force && brew upgrade --cask Shawshank01/tap/vidbutler
   ```

   Если вы установили VidButler непосредственно из DMG, выберите **Открыть выпуск на GitHub**.
3. Чтобы проверить обновления вручную, нажмите значок VidButler и выберите **Проверить обновления**.

> [!NOTE]
> При запуске из исходного кода или распакованной сборки для Linux пункт **Проверить обновления** предлагает открыть [последний выпуск](https://github.com/Shawshank01/Vidbutler/releases/latest).

## Используемые проекты

- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — основной механизм скачивания медиа
- [FFmpeg](https://ffmpeg.org/) — обработка и перекодирование аудио и видео, встраивание субтитров
- [Deno](https://deno.com/) — лёгкая среда JavaScript для решения проверок в yt-dlp
- [Electron](https://www.electronjs.org/) — фреймворк для настольных приложений
